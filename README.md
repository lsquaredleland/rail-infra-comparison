# Infrastructure Comparison

An interactive map that overlays up to four cities or regions at true scale: city limits, rail networks, stations and main roads, all from
OpenStreetMap. It is a static site (`site/index.html`, canvas, no framework, no build step) plus one JSON file per region in `site/data/`.

## Run the site

    cd site && python3 -m http.server 8765      # then open http://localhost:8765/index.html

Roads load only when you switch the map to "+ Streets". Zoom thresholds for station dots and names are in `site/config.js`.
The panel's "Drawing" switch (or `?renderer=webgl`) draws the map with deck.gl on the GPU instead of the 2D canvas, for comparison; deck.gl
(`site/vendor/`, MIT, (c) vis.gl contributors) loads only then.

## Build the data

You only need this to regenerate `site/data/`. It starts from the OSM planet file (`../osm-rail/planet-260928.osm.pbf`, or set `RA_PLANET`).

    pip install -r requirements.txt              # shapely, pyproj, numpy
    brew install rust
    pipeline/refresh.sh                          # extract all groups, build all 21 regions, station model: about 3 minutes
    pipeline/refresh.sh prd hk,sz                # one-off: one group, some regions

Monthly refresh: point `RA_PLANET` at the new planet and run `pipeline/refresh.sh`. New city: add a group to `pipeline/groups.json` and a
region to `REGIONS` in `pipeline/build.py`, then `pipeline/refresh.sh <group> <region>`. `docs/rust-pipeline.md` describes the extraction and build pipeline in depth (design, code, optimizations, how to reuse it). `CLAUDE.md` explains the data format, the station model,
the checks each build prints and the timings.

## Deploy

The site is static, so any static host works. On Vercel: import the repository, set **Root Directory** to `site` and leave the build command empty;
`site/vercel.json` sets the cache headers (data files are cached for an hour, then revalidated). The data is built locally with
`pipeline/refresh.sh` and committed, so a monthly refresh is: run it, commit `site/data/`, push; Vercel redeploys on its own.

## Test

    pip install -r requirements-dev.txt
    python3 tests/smoke.py                       # needs the site served on :8765 and Chrome installed

## What is in the repository, and how large

Pushed (about 11.3 MB; git compresses it to roughly a third; no file over 1 MB):

| Part | Size | Files |
|---|---|---|
| `site/data/<id>.json` main region files, loaded when a city is chosen | 5.8 MB (1.8 MB gzip) | 21, from 35 KB (San Francisco) to 774 KB (Greater Bay Area) |
| `site/data/<id>.roads.json`, loaded only with the "+ Streets" layer | 2.8 MB (1.1 MB gzip) | 21, from 26 KB to 387 KB |
| `site/data/stations_hk.json`, `stations_sz.json` (station model) | 1.6 MB (0.3 MB gzip) | 2, 607 KB and 975 KB |
| `site/index.html`, `site/config.js`, `site/data/index.json` | 0.1 MB | 3 |
| `site/vendor/deck.gl-9.3.11/` (core, layers, extensions; MIT), loaded only in WebGL mode | 0.9 MB (0.26 MB gzip) | 4 |
| `extract/` (Rust source), `pipeline/`, `tests/`, `docs/`, licences, requirements | 0.2 MB | 19 |

Not pushed (in `.gitignore`, regenerated by `pipeline/refresh.sh`): `run2/` about 470 MB (extracted jsonl), `extract/target/` (Rust build),
`pipeline/qa/` 0.2 MB (check output). The planet file is outside the repository.
